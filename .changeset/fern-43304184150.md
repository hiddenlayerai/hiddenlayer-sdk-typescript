Generated from the API specification

- added: `clientId` and `clientSecret` client options, read from `HIDDENLAYER_CLIENT_ID` and `HIDDENLAYER_CLIENT_SECRET` when they aren't passed. The client fetches a token from `POST /oauth2/token` on its first call, reuses it, and fetches a new one two minutes before it expires. The `token` option works as before.
- added: enum type ActorType member THIRD_PARTY_TOKEN
- changed: a client with neither credentials nor a token now throws when it's constructed, rather than failing on its calls. Pass `auth: false` for a client that sends no `Authorization` header.
- removed: the `OauthScope` type, an enum of permission names that no method took or returned
